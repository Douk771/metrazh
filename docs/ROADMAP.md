# Метраж: что сделано и что в планах

Документ для всех, кто работает над проектом, включая их ИИ-ассистентов.
Правила работы с кодом — в [CLAUDE.md](../CLAUDE.md). Обновляйте этот файл вместе с изменениями.

Сайт: https://metrazhpro.ru

## Что это

PWA для риелторов: готовит материалы по объекту недвижимости. Всё работает в браузере, без сервера;
данные хранятся только в IndexedDB на устройстве. Чистый JS без сборки, хостинг GitHub Pages.

Путь пользователя: новый объект (адрес или название) → Фото → План → Текст → Презентация.

## Уже есть

- **План:** комнаты, готовые заготовки, растягивание за стены и углы, двери и окна, участок с кадастровым номером,
  подложка БТИ или ЕГРН с масштабом, автораспознавание комнат на плане.
- **Мебель:** условные знаки вида сверху, выделение, ручки на сторонах, размеры в сантиметрах, значок поворота.
- **Фото:** порядок, поворот, водяной знак, улучшение (авто, яркость, контраст, красочность), ZIP и меню телефона.
- **Текст:** заголовок и описание объявления, собранные из данных объекта; кнопки Авито, ЦИАН и Домклик
  копируют описание и открывают форму, значения для полей копируются по одному.
- **Презентация:** PDF в палитре бренда, листы картинками и формат сторис 9:16.
- **Визитка:** контакты агента, QR-код с контактом (vCard), картинка и файл `.vcf`.
- **Оформление:** градиент, цветные вкладки разделов, шкала заполнения, стрелка «дальше», справка с поиском.
- **Копии объектов:** выгрузка и загрузка файла `.metrazh.json`.

## Сознательно отложено

Не начинать без решения владельца проекта.

- **Оплата:** разовая 499 ₽ за проект через СБП. Кнопка оплаты появляется после превью презентации,
  после оплаты открывается выгрузка. Без сервера проверка оплаты обходится, поэтому нужен хотя бы небольшой сервер,
  который подтверждает платёж. За оплату переедут скачивание и меню телефона, включая «Поделиться» у презентации.
- **Каталог типовых серий домов:** найти похожую планировку, затем перерисовать её в редакторе и добавить мебель.

## Следующие задачи

### Проверить на настоящих устройствах
Пока всё проверялось в браузере на компьютере, в том числе на ширине телефона. Не проверены:
- автораспознавание на настоящем снимке плана БТИ (проверялось только на синтетических планах);
- меню телефона: пункт «Сохранить изображения» на iPhone, пункты на Android, предел по числу фото;
- работа пальцем: растягивание стен, ручки и значок поворота у мебели;
- сканирование QR-кода визитки камерой iPhone и Android и сохранение контакта;
- улучшение фото в Safari (там работает запасной попиксельный способ);
- вопрос о названии нового объекта (обычный `prompt`) и его вид на телефоне.

### Оформление
- Экран приветствия с логотипом: «приветствуем тебя, агент по недвижимости, я буду твоим помощником». Нужен файл логотипа.
- Настоящий логотип и шрифт из макета вместо системного жирного. Нужны файлы.
- Значок приложения пока старый, под новую палитру его ещё не переделывали.
- В макете вкладки пройденных разделов уезжают стопкой вверх. Сейчас это цветная строка:
  стопка занимала бы около трети экрана телефона и урезала чертёж. Менять только по решению владельца.

### План и мебель
- Комнаты сложной формы: инструмент «Контур» убран по просьбе из макета, вручную Г-образную комнату теперь не нарисовать.
  Такие комнаты появляются только через сканер. Нужно решение, как их рисовать.
- Магнит «вершина к вершине»: сейчас комнаты прилипают к линиям стен.
- Мебель из заготовки должна вставать к глухой стене без окон; сейчас место фиксированное.
- Загрузка плана ЕГРН прямо в разделе участка; сейчас общий блок «Подложка». Кадастровый номер в презентацию не выводится.
- Старые объекты остаются с толщиной стен 12 см, новые 20 см, поля для изменения нет.

### Надёжность
- Одна кнопка для копии всех объектов и напоминание её делать.
- Память на iPhone: готовить фото для PDF постранично.
- Подсказка «Доступно обновление» вместо тихой подмены версии.
- Автотесты на Node для геометрии, QR-кода и сборки текста. Сейчас тестов в репозитории нет.

### Идеи, можно не делать
- Автопостинг на площадки: нужен сервер, публичные ссылки на фото, доступы к аккаунтам и отдельная интеграция
  с каждой площадкой. Возвращаться вместе с оплатой и после разговора с риелторами. Клики по сайтам роботом не делать.
- Кнопка для Дом.РФ: портал не открылся (403), публичную форму объявления найти не удалось. В PDF он упомянут,
  но пока вместо него Домклик. Уточнить, что имелось в виду.
- QR-код визитки на обложке презентации.
- Автозаполнение адреса в презентации из названия объекта.
