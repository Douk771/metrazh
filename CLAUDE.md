# Метраж

PWA для риелторов: планировки, фото с водяным знаком, (дальше) PDF-презентация.
Всё работает в браузере, без сервера; данные — только в IndexedDB на устройстве.
Чистый JS (ES-модули), без сборки. Хостинг — GitHub Pages (Douk771/metrazh, ветка main, корень).

## Правила
- Каждая новая функция или изменение поведения → обновить справку «Как это работает» в `js/help.js`
  (раздел на функцию, простым языком для риелтора). Справка — часть фичи, без неё фича не готова.
- Новый JS-файл → добавить в список `SHELL` в `sw.js` и поднять версию `CACHE`.
- Оплата, коды активации и лимиты пока сознательно не делаем.

## Локальный запуск
`python3 -m http.server 8765` в корне и открыть http://localhost:8765
