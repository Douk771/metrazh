# Метраж

Планировки и фото объектов недвижимости прямо на телефоне.

- Редактор планировки с автоподсчётом площадей (как в техпаспорте: по внутреннему контуру).
- Фото пакетом, водяной знак (логотип + подпись), выгрузка ZIP-архивом.
- Работает офлайн, ставится на экран «Домой». Фото и планировки не покидают устройство.

Справка — в самом приложении, кнопка «?».

Локально: `python3 -m http.server 8765` → http://localhost:8765

Планы и текущее состояние — в [docs/ROADMAP.md](docs/ROADMAP.md).
